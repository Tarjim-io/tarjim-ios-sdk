# Security

Please report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this repository.
Do not open a public issue for it.

Include what you found, how to reproduce it, and the SDK version. We aim to acknowledge a report within three working
days and to keep you informed until it is resolved.

In scope: anything that could expose an API key, serve text that does not match a release's hashes, write outside the
SDK's own directory, or crash an app that uses the SDK.
